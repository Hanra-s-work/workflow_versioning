# multi in one (python)

## Goal

This is the folder containing code that is in charge of being able to:

* set up an environement
* compile the program
* create a library of the program
* run the raw version of the program
* create it's documentation

## Getting started

### Mac/Linux

In order to start the program, you will need to be (in your terminal) at the root of the project (this is where `run_me.sh` is located) and run the following command: `chmod +x ./run_me.sh && ./run_me.sh`, this command will ensure that the script has executable rights as well as start it.

### Windows

Just run the `run_me.bat` script.
